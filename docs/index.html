  1. Click Done (don’t move it to the Bin).

  1. Done চাপুন (Bin-এ ফেলবেন না)।
  2. System Settings → Privacy & Security খুলুন।
  3. নিচে স্ক্রল করে Open Anyway ক্লিক করুন, Mac-এর পাসওয়ার্ড দিন, তারপর Open।

অ্যাপটা App Store-এর বাইরে থেকে আসায় এটা শুধু প্রথমবার হয়।

Which colour profile should I use?কোন কালার প্রোফাইল ব্যবহার করব?

Open Preferences (⌘,) and pick the same CMYK profile your Illustrator uses (Edit → Color Settings). Coated FOGRA39 is common for offset printing in Bangladesh — or ask your press.

Preferences (⌘,) খুলে Illustrator-এ যে CMYK প্রোফাইল আছে সেটাই দিন (Edit → Color Settings)। বাংলাদেশে অফসেট প্রিন্টে সাধারণত Coated FOGRA39 — অথবা প্রেসে জিজ্ঞেস করুন।

Can I edit my .ai file again in this app?.ai ফাইল কি এই অ্যাপে আবার এডিট করা যাবে?

No — always keep your working file as .vpm. The .ai and .eps exports are for Illustrator and the press; text in them is converted to outlines.

না — কাজের মূল ফাইল সবসময় .vpm-এ সেভ রাখুন। .ai আর .eps হলো Illustrator আর প্রেসের জন্য; এগুলোতে টেক্সট outline হয়ে যায়।
